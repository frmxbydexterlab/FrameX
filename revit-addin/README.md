## 📌 Overview

The **FrameX Revit Add-in** is a native C# Autodesk Revit plugin that bridges high-level architectural BIM models with the FrameX cloud computational framing engine.

### Key Capabilities
1. **Intelligent Wall & Opening Extraction (`ExportWallsCommand.cs`)**:
   - Extracts wall curve geometry, baseline coordinates, thickness, and compound structural layers.
   - Detects all window, door, and generic opening penetrations with exact 3D bounding coordinates.
   - Identifies wall corner conditions, T-intersections, and non-orthogonal wall joins.
   - Packages the extracted geometry into an encrypted `.wex` (Wall Exchange) container for the framing API.
2. **Automated 3D Framing Generation (`ImportFramingCommand.cs` & `FramingBuilder.cs`)**:
   - Ingests calculated framing layouts from the FrameX engine.
   - Dynamically instantiates native Revit structural framing families (`FamilyInstance`) for C-studs, U-tracks, headers, sills, and noggings directly inside the Revit project coordinate system.
3. **Parametric LGSF Family Library (`Families/`)**:
   - Comprehensive library of `.rfa` structural framing families (SSMA C-studs, tracks, clip angles, straps, and service hole penetrations).

## 💻 Quick Installation

### Option A: 1-Click Windows Installer (Recommended)
You can directly run the pre-built installer:
```
revit-addin/installer/LGSFRevitAddin_Installer.exe
```
The installer automatically detects installed Autodesk Revit versions (2021 through 2025), deploys the plugin manifests to `%APPDATA%\Autodesk\Revit\Addins\`, and registers the required steel profile family definitions.

### Option B: Build from Source
Requirements:
- Visual Studio 2022 (with .NET Desktop Development & .NET 8.0 SDK)
- Autodesk Revit 2021–2025 SDK references

1. Open `LGSFRevitAddin.csproj` in Visual Studio.
2. Select target build configuration (e.g., `Release` / `x64`).
3. Build the solution. The build targets automatically deploy `LGSFRevitAddin.dll` and `LGSFRevitAddin.addin` to:
   ```
   %APPDATA%\Autodesk\Revit\Addins\<Revit-Version>\
   ```

## 🛠️ Usage in Autodesk Revit

Once installed, a new **FrameX / LGSF** tab appears in the Revit Ribbon:

1. **Export Walls to FrameX**:
   - Click **"Export Walls"** in the FrameX ribbon panel.
   - Select the target architectural walls (or export all walls in active view).
   - The plugin extracts the walls, resolves layer offsets, and generates an encrypted `.wex` export file.
2. **Import Framing into Revit**:
   - Click **"Import Framing"** and select the framing solution generated by FrameX.
   - The add-in automatically places native 3D light-gauge steel members aligned with structural layers, openings, and joins.

## 📁 Source Code Structure

```
revit-addin/
├── Commands/
│   ├── ExportWallsCommand.cs      # User command to select & extract walls
│   ├── ImportFramingCommand.cs    # User command to construct 3D members in Revit
│   └── ExportFamilyCommand.cs     # Family validation & extraction helper
├── Core/
│   ├── WallExtractor.cs           # Parametric geometry & opening extraction
│   ├── FramingBuilder.cs          # Native Revit FamilyInstance creator
│   ├── TypeGenerator.cs           # Dynamic structural type generator
│   ├── WallSelectionFilter.cs     # Interactive Revit UI selection filter
│   └── SecurityHelper.cs          # AES-GCM encryption for .wex data
├── Models/
│   ├── WallExportData.cs          # Serialized BIM wall schema
│   └── FramingData.cs             # Member coordinate & profile definitions
├── Families/                      # Autodesk Revit .rfa family library
├── installer/
│   └── LGSFRevitAddin_Installer.exe # Pre-compiled one-click installer
├── App.cs                         # Revit IExternalApplication ribbon setup
├── LGSFRevitAddin.addin           # Autodesk Revit addin manifest
├── setup.iss                      # Inno Setup compilation script
└── LGSFRevitAddin.csproj          # C# multi-targeting project file
```
